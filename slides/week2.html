Review · week 1

Can the code be swapped back?

A school replaces each of its 500 pupil numbers with a random code from 1,000 possible codes, never giving one code twice. As a map from pupils to the 1,000 codes, what is it?

A bijection
Injective, not surjective
Surjective, not injective
Not a function
Why. No two pupils share a code (injective), but half the codes are never used (not surjective). On its 500 pupils and the codes used, it can still be inverted.

Answer B. Point out the last sentence: injective is what makes a code reversible. Week 6 shows that reversibility is not the only route back to a person.

Block A · propositions

A proposition is true or false, and connectives build bigger ones

SymbolReadsTrue when
¬pnot pp is false

p → qif p then qp is false, or q is true
p ↔ qp if and only if qboth have the same value

"Or" is inclusive: both true counts. The exclusive or of everyday speech ("tea or coffee") is a different connective. "The parcel is heavy" is a proposition; "lift the parcel" is not, as it is neither true nor false.

Implication

"If p then q" is broken only by p true and q false

  • A light parcel lifted by two people does not break the rule
  • A light parcel makes the rule true whatever happens: vacuously
  • Only a heavy parcel lifted alone breaks it

Ask the room to find the only row that breaks the rule before revealing the column. The two rows where p is false surprise people: the rule says nothing about light parcels, and a rule that says nothing is not broken.

In code

A truth table is a loop over every row of truth values

import itertools

def implies(a, b):
    return (not a) or b

for p, q in itertools.product([False, True], repeat=2):
    print(p, q, implies(p, q))
  • n variables give 2ⁿ rows: 4 for two, 1,024 for ten
  • Checking every row is a proof for a finite claim
  • For 50 variables, 2⁵⁰ rows is out of reach: that is where a solver comes in

The first lab task writes this as a function. Stress the second bullet: when the cases are finite and few, testing every one of them is a proof, not merely a test.

Equivalence

Two formulas are equivalent when they agree on every row

LawEquivalent pair
De Morgan¬(p ∧ q) and ¬p ∨ ¬q; ¬(p ∨ q) and ¬p ∧ ¬q
Contrapositivep → q and ¬q → ¬p
Implication as orp → q and ¬p ∨ q
Distributionp ∧ (q ∨ r) and (p ∧ q) ∨ (p ∧ r)
Not a law. The converse q → p is a different rule: a parcel lifted by two people need not be heavy.

Each line can be checked by a four- or eight-row table, which the lab does in code. The converse is the most common error in reading rules: watch for it in the checkpoint.

Why. The contrapositive ¬q → ¬p agrees with p → q on all four rows.

Block B · arguments

An argument is valid when no row makes the premises true and the conclusion false

FormPremisesConclusionVerdict
Modus ponensp → q, pqvalid
Modus tollensp → q, ¬q¬pvalid
Affirming the consequentp → q, qpinvalid: row p F, q T
Denying the antecedentp → q, ¬p¬qinvalid: row p F, q T

Validity is about form, not truth: a valid argument from a false premise can reach a false conclusion.

The search for a counterexample row is the whole method, and it is the same idea as a counterexample to a claim in week 3. The lab writes it as a function and runs it on the centre's consent rule.

Rules in words

Words like "only if" and "unless" fix the direction of the arrow

WordsFormula

Habit. Name each variable in one line, write the formula with brackets, then read it back in words.

Example to work aloud: "A member may borrow a laptop only if they have signed the agreement" is borrow → signed; signing does not entitle anyone to a laptop. The bracket line is where access rules go wrong, and the lab has one.

Block C · normal form

Conjunctive normal form is an "and" of clauses, each an "or" of literals

(a ∨ b) ∧ (¬a ∨ c) ∧ (¬b ∨ ¬c)

  • A literal is a variable or its negation
  • A clause is an or of literals: at least one must hold
  • Every formula has an equivalent CNF: one clause per row it must exclude

For a solver

Variables are numbers and a clause is a list: [1, 2], [-1, 3], [-2, -3]. A minus sign is "not".

Build the CNF of p → q on the board from its table: the only false row is p T, q F; excluding it gives the clause ¬p ∨ q. That is how "every formula has a CNF" is proved, one excluded row at a time.

Satisfiability

A SAT solver finds a row that makes every clause true, or proves there is none

Encodeone variable per yes-or-no decision; one clause per rule
→
Solvea model: a value for every variable, or "unsatisfiable"
→
Checkthe model against the rules in words, with separate code
  • Checking a proposed assignment is quick; finding one can take exponential time in the worst case with every known method
  • "Unsatisfiable" is a proof that no assignment works; a solver can name a small set of rules that already conflict

Tools are examples: the lab uses PySAT; Z3 fills the same slot. The third step is the course's habit: a solver satisfies the clauses you gave it, not the rules you meant.

Week 2 · wrap-up

Three things to keep

Only one row breaks "if"

p true and q false. The converse is a different rule.

Validity is a row search

Look for premises true and conclusion false. None found in every row: valid.

Encode, solve, check

A solver meets the clauses you wrote. Check its answer against the words.
